# 🛒 VyaparDrishti
### E-Commerce Competitor & Pricing Intelligence Platform

> "VyaparDrishti" = Business Vision (Hindi)

## 🎯 Project Overview
An end-to-end data intelligence platform that analyzes Amazon product reviews to extract:
- **Pricing Intelligence** using XGBoost regression
- **Sentiment Analysis** using TF-IDF & BERT
- **Competitor Benchmarking** across product categories
- **Interactive Dashboard** built with Flask + Plotly

## 🛠️ Tech Stack
| Layer | Tools |
|-------|-------|
| Data | Python, Pandas, SQL |
| ML | XGBoost, Scikit-learn, BERT |
| NLP | TF-IDF, HuggingFace Transformers |
| Backend | Flask, SQLAlchemy |
| Frontend | Plotly Dash |

## 📁 Project Structure

    VyaparDrishti/
    ├── data/           → Raw & processed datasets
    ├── notebooks/      → EDA & model training
    ├── models/         → Saved ML models
    ├── flask_app/      → Web application
    ├── reports/        → Charts & outputs
    └── config.py       → Global config

## 🚀 Setup Instructions
```bash
git clone https://github.com/Omkar-Praksh-Patil/VyaparDrishti.git
cd VyaparDrishti
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
